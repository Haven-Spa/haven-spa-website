# Haven Spa Website

Public-facing website and booking/payment interface for Haven Spa.

---

## Overview

The Haven Spa Website provides:

- Brand presentation
- Service information
- Online booking
- QR payment generation
- Payment initialization
- Customer session activation

This is the customer entry point to the Haven Spa ecosystem.

---

## Core Features

- Landing page
- Service pricing display
- Session booking
- MoMo payment initiation
- Real-time payment confirmation
- Session token generation
- API communication with CMS

---

## Tech Stack (Recommended)

- Next.js
- TypeScript
- TailwindCSS
- Axios (API calls)

Optional:
- Stripe-style payment UI patterns
- QR code generation library
